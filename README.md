# Замер скорости скачивания на Node.js

## Запуск

- npm start -- "https://example.com/image.jpg"

Скрипт выполняет 10 последовательных GET-запросов. Тело каждого ответа читается до конца по частям, без сохранения на диск. HTTP-перенаправления обрабатываются автоматически.

- **Среднее время запроса** в миллисекундах включает ожидание ответа и чтение всего тела.
- **Общий объём** в байтах считается по телам всех ответов. Если сервер использует HTTP-сжатие, учитывается размер после распаковки.
- **Скорость** выводится в МиБ/с (1 МиБ = 1 048 576 байт). Скрипт делит общий объём на суммарное время запросов.

При сетевой ошибке, HTTP-статусе вне диапазона 2xx или превышении лимита в 120 секунд на один запрос скрипт выводит ошибку и завершается с кодом 1.

## Структура проекта

- `download-speed.js` проверяет адрес, запускает запросы по очереди и печатает результат.
- `src/download.js` читает тело одного ответа и возвращает его объём и время загрузки.
- `src/statistics.js` рассчитывает итоговые показатели.
- `package.json` задаёт версию Node.js и команду запуска.
